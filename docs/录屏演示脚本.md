# SuiEye 淬眸 · 录屏演示脚本（演示顺序 + 字幕）

> 面向汇报 / 答辩 / 对外展示场景。配套视频生成提示词（MiniMax H3）见文末，可渲染成片头、转场、片尾后拼接进录屏。
> 平台定位：**铅锌矿浮选过程智能视觉分析平台** —— 以泡沫 / 颗粒图像与巡检画面为输入，覆盖品位预测、粒度分析、安全巡检、尾矿、水系统与设备健康六条业务线，接入凡口铅锌矿真实生产化验数据。
>
> ⚠️ 本版已对齐**最新系统（2026-10-19 门面化）**：首页 `/` 是 **3D 数字孪生导览屏（Equipment3D.vue）**，**3D 就在首页**。汇报动线遵循系统自身设定：**门面（讲厂区）→ 直播墙（讲全厂运行）→ 各专题页**。

## 2. 分镜脚本（顺序 + 字幕）

### 镜 1 ｜ 3D 门面首页 — 开场 wow
**画面动作**：进入 `http://127.0.0.1:5188`，首屏即为 3D 数字孪生厂区。先给 2–3 秒全景（可轻微拖拽旋转/缩放展示 3D 可交互），然后鼠标自上而下轻扫：品牌页头「SuiEye 淬眸 · 铅锌浮选全流程智能视觉分析平台」→ 中间 4 个 KPI 格 → 右上「进入直播墙」按钮与「N 项需关注」胶囊 → 左上「厂区导览」浮层 → 右下「数字孪生同步」HUD。
**字幕 / 旁白**：
> 欢迎来到 SuiEye 淬眸——铅锌浮选全流程智能视觉分析平台。打开首页，您看到的是一座 **3D 数字孪生厂区**：整座厂的实时工况、每一条业务线的入口，都落在这张图里。页头四个数回答"这座厂现在怎么样"——铅品位均值、最新一次分析、回用水质、设备健康度；右侧可直接进入直播墙或跳转告警。这不是菜单，是整座厂的活地图。

**精剪（45s）**：只给全景 + 4 KPI + 右上 CTA 高亮，不展开浮层。
**备注**：门面指标口径已在代码里标死（如"Pb 品位均值"是 N 次分析统计均值，副行写统计区间），讲的时候强调"均值≠单次"，与老板"数据不能假"的口径一致。

### 镜 2 ｜ 门面交互 — 空间即入口
**画面动作**：
① 点左上「厂区导览」浮层里的 **浮选段**（绿色主段）→ 相机飞向浮选槽并高亮该段设备，浮层展开显示「进入功能：实时品位监控」+ 段内设备清单；
② 在 3D 里**双击一台浮选设备**→ 弹出设备详情面板，顶部醒目按钮「进入实时品位监控」→ 点击进入 `/monitor`；
③ 收起浮层（一点变纯厂区），再点开「公辅与中控」：依次扫过 中控室（报表/告警/总览/时光机）、化验室（浮选/安全工作台）、药剂间（配药）、配电室（设置）、监控立杆（实时监控）。
**字幕 / 旁白**：
> 门面最核心的设计是"空间即入口"。左侧厂区导览按真实物料流向排布——磨矿、浮选、精矿、尾矿与回水四段，点一段相机就飞过去并高亮该段设备；双击任意设备，直接进它所属业务线的功能页。右侧公辅建筑也一一对应：中控室管总览与告警，化验室做分析，药剂间配药，配电室管设置，监控立杆接现场画面。整座厂，一处入口。

**精剪（40s）**：只演示"双击浮选设备 → 进实时监控"这一条最亮的交互，其余口述带过。
**备注**：浮选段 `primary:true`，是视觉主色，点击/飞行反馈最明显，优先用它演示。

### 镜 3 ｜ 直播墙 — 全厂运行一屏纵览
**画面动作**：从门面右上「进入直播墙」进入 `/livewall`。鼠标自上而下扫：顶部全厂 KPI → 中部工艺流程节点流光 → 品位趋势曲线 → 右侧实时告警轮播 → 底部浮选泡沫实时画面（froth-loop.mp4 循环）。
**字幕 / 旁白**：
> 从门面进入直播墙，一屏纵览全厂运行：核心 KPI、磨矿—浮选—脱水—尾矿的工艺全景流光、铅锌品位趋势曲线、实时滚动告警，以及底部浮选泡沫的实时画面。这是给调度与参观用的"全厂总览"，30 秒自动刷新，所有数据来自真实生产台账。

**精剪（40s）**：高亮 KPI 行 + 品位趋势 + 泡沫实时画面三处。

### 镜 4 ｜ 实时监控大屏 — 真实数据背书（旗舰）
**画面动作**：进入 `/monitor`。展示单点位大屏：凡口 2019 真实录像逐帧驱动画面 + 右上"数据时钟"显示 30× 快进 + 右侧曲线/工艺链参照带随录像时刻联动。强调"视频播到哪，曲线数值就同步到哪"。
**字幕 / 旁白**：
> 这是平台的旗舰页——实时监控大屏，画面是凡口铅锌矿 2019 年的真实生产录像，逐帧驱动。右上角数据时钟以 30 倍速快进，曲线和工艺链参照带与录像时刻严格同步：视频播到哪一分，曲线就落到那一刻的真实品位。我们用一条真实产线，把"算法准不准"摊在阳光下验证。

**精剪（60s）**：只讲"录像驱动 + 时钟 30× + 曲线联动"三件事，进度条拖到不同时间点佐证同步。
**备注**：这是老板最看重的"数据可信"证据，建议完整保留。

### 镜 5 ｜ 浮选品位预测 — 核心能力
**画面动作**：进入 `/workbench/flotation`。拖入 `样例图像/泡沫样例1.jpg` 或点"分析当前画面"→ 点"开始分析" → 展示：预测卡（Pb / Zn 品位）、管线执行轨迹（各 Filter 耗时）、图像结果 Tab（分割叠加 / ROI / 概率热图 / 彩色标签）、右侧 11 维泡沫视觉特征表。
**字幕 / 旁白**：
> 平台的核心视觉能力是浮选泡沫品位预测。上传一张泡沫图像，系统走完整 Filter 管线：ROI 提取、MSR 增强、分水岭分割，再提取 11 维形态特征，由 XGBoost 回归同时给出铅、锌双金属品位。右侧是分割结果与模型置信度，全过程通常不足 1 秒。

**精剪（60s）**：拖图 → 分析 → 高亮 Pb/Zn 预测值与"生成配药方案"按钮。

## 5. 录制小贴士

- **开场别急着点**：门面首页是"门面担当"，先给 2–3 秒 3D 全景再开始旁白，第一印象最值钱。
- **强调"真实数据"**：监控大屏的凡口录像、化验台账（62,798 条真实记录）是评委最关心的可信度证据，多停留。
- **闭环叙事**：预测（镜 5）→ 配药（镜 6）→ 告警（镜 10）是一条完整业务链，讲的时候点明"这是闭环"。
- **避免口径翻车**：品位字段讲"均值/最新"而非"全厂品位"；监控立杆讲"1 路在线"而非"4 路"（系统文案已据此修正，照着屏幕念即可）。
- **H3 片头/片尾**建议最后单独渲染拼接，不占用录屏实操时间。
