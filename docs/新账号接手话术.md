## 铁律（务必守住，详细版在 HANDOFF.md 第二、六节）

- FastAPI 入口是 `backend.main:app`，且**必须从项目根目录启动**（在 backend/ 里起会报 ModuleNotFoundError）
- 前端 axios 已自动解包 `res.data`；`api` 的 baseURL 已含 `/api`，调用时**不能再带 `/api`**
- Filter 注册只能写 `backend/engines/filters/__init__.py`，单个 filter 文件里禁止注册
- 品位字段名是 `pb_grade_xrf` / `zn_grade_xrf`（不是 pb_grade / zn_grade）
- 品牌全称固定为「SuiEye 淬眸 · 铅锌浮选全流程智能视觉分析平台」，**西文在前**，不要再写「淬眸 SuiEye」
- 本机 curl 测本地服务必须加 `--noproxy "*"`（否则 502）
- **「启动服务 + 探针/截图」必须写在同一条命令里**（vite/后端进程会在回合结束时被回收）
- 测试前先查端口残留（旧进程抢答会让你误判"改动没生效"）
- 探针收尾用 CDP `Browser.close`，不要 `terminate()`（会打崩 vite）
