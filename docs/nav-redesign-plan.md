# 状态栏重构方案（左栏全局导航 + 3D 页左栏）

> 2026-10-19 · 针对老板反馈「左侧选项部分也要重新设计，两个部分现在好多重复的，整体也很奇怪」
> 结论先行：**左侧两条竖栏做分工，不做两张菜单。**

---

## 一、问题诊断（先摆事实）

截图里有三条竖栏：**A 全局侧栏（220px）｜B 厂区导览（240px）｜C 3D 视口**。
A 和 B 同时在场，就必然重复。逐条对齐现状：

| 功能页 | 全局侧栏 A | 厂区导览 B | 状态 |
|---|---|---|---|
| `/dashboard` 仪表盘 | 运营 → 仪表盘 | 中控室 → 生产总览 | **重复，且名字不同**（同一个页面两种叫法）|
| `/alarms` 告警 | 资产 → 告警 | 中控室 → 告警中心 | **重复，名字不同** |
| `/reports` 报表 | 资产 → 报表 | 中控室 → 报表统计 | **重复，名字不同** |
| `/timemachine` 时光机 | 运营 → 时光机 | 中控室 → 工况时光机 | **重复，名字不同** |
| `/workbench/flotation` 分析工作台 | 运营 → 分析工作台 | 化验室 → 浮选工作台 | **重复，名字不同** |
| `/dosing` 配药助手 | 资产 → 配药助手 | 药剂间 → 配药助手 | **重复** |
| `/settings` 设置 | 系统 → 设置 | 配电室 → 系统设置 | **重复，名字不同** |
| `/livewall` 直播墙 | 运营 → 直播墙 | 监控立杆 → 直播墙 | **重复** |
| `/monitor` 实时监控 | 运营 → 实时监控 | 浮选段（需展开）| 重复（B 藏在展开层）|
| `/safety` 安全巡检 | 资产 → 安全巡检 | 精矿输送（需展开）| 重复（B 藏在展开层）|
| `/tailings` 尾矿处理 | 资产 → 尾矿处理 | 尾矿与回水（需展开）| 重复（B 藏在展开层）|
| `/water` 水质监测 | 资产 → 水质监测 | 尾矿与回水 → 水质监测 | 重复（B 藏在展开层）|

**14 个功能页里，B 覆盖了 10 个、A 覆盖了 13 个 —— 两个栏目 9 个完全重合。**

再叠加四个"看着奇怪"的具体成因：

1. **同一功能有 2~3 个名字**。`仪表盘 = 生产总览`、`告警 = 告警中心`、`报表 = 报表统计`、
   `时光机 = 工况时光机`、`分析工作台 = 浮选工作台`、`设置 = 系统设置`。
   用户每跳一次页，标题就换一次名字 —— 这是"不像一个系统"的最大来源。
2. **B 栏把功能分成了两种交互**：工艺段要**点击展开**才看到里面有功能（收起时点行只是让相机飞过去），
   而公辅载体是**直接暴露 chip**。同一条左栏里存在两种"能不能点"的语法，用户不知道该不该点。
3. **两栏的"分组逻辑"互斥**：A 按「运营 / 资产 / 系统」分（人的职责），
   B 按「工艺流程 / 公辅载体」分（物理空间）。同一批功能被两套分类各切一遍，切完对不上。
4. **B 栏在 3D 页占了 240px，把 3D 视口挤到 928px**（1440 屏）—— 视口一窄，
   相机就得后撤，配电室那种边缘建筑就不断溢出。**竖栏的宽度直接变成了 3D 的构图问题。**

> 一句话：A 是"功能菜单"，B 是"同一份功能按车间又排了一遍"。重复是结构性的，调样式救不回来。

---

## 二、设计原则（定调）

1. **一个页面只有一张"能去别处"的菜单。** 重复的入口不是"冗余便利"，是"两套信息架构在打架"。
2. **左侧栏管"去哪"，正文管"看什么"。** 3D 是正文，不是导航——它负责的是"厂区现在什么样"。
3. **功能名全站唯一。** 一处叫"告警中心"，处处叫"告警中心"（或统一叫"告警"），不许换皮。
4. **空间关系不靠第二张菜单表达，靠 3D 场景本身表达。** 点设备就等于点左栏那一项，不需要左边再列一遍。

## 三、三个方案

### 方案 0 · 现状（基线）
- **结构**：A 220px 平铺菜单（3 组 13 项）+ B 240px 厂区导览
- **优点**：3D 页信息密度高；空间隐喻完整
- **缺点**：上面列的 4 类问题全中；3D 视口仅剩 928px
- **结论**：❌ 不可接受

---

### 方案 A · 「入口二选一」（最小改动，半天量级）

**核心**：把 3D 页的 B 栏**整块删掉**，A 栏改成"能进 3D 的结构"。

```
A 栏（全局，220px）                      3D 视口（拉宽到 1168px @1440）
┌────────────────────┐                 ┌──────────────────────────────┐
│ 淬眸 SuiEye         │                 │                              │
├────────────────────┤                 │        完整厂区              │
│ 智能工厂  ← 默认    │                 │     （左上角一个小图例）      │
│   · 磨矿段 70%     │  ← 悬停才展开    │                              │
│   · 浮选段 86%     │                 │                              │
│   · 精矿输送 33%   │                 │                              │
│   · 尾矿回水 87%   │                 │                              │
│ 直播墙             │                 │                              │
│ 实时监控           │                 │                              │
│ 仪表盘             │                 │                              │
│ 时光机             │                 │                              │
│ 分析工作台         │                 │                              │
│ …                  │                 │                              │
└────────────────────┘                 └──────────────────────────────┘
```

- 3D 页里**点工艺段/设备/建筑**仍然进对应功能（拾取逻辑一行不改）
- A 栏的 4 个工艺段是**只读的状态行**（显示 % 与故障数），点击 = 让相机飞到那段，**不承担跳转**
- 公辅载体（中控室/化验室/药剂间/配电室/监控立杆）**不在左栏出现**，只在 3D 里点

| | |
|---|---|
| ✅ 优点 | 改动最小；重复彻底消失；视口从 928 → 1168px，边缘建筑不再挤 |
| ❌ 缺点 | 3D 页失去了"按车间找功能"的帮助，新用户得先点建筑才知道里面有啥；厂区导览这个好设计被浪费 |
| 🎯 适合 | 只想止血、不打算再投入 |

### 方案 B · 「左栏唯一 + 3D 图上导览」★ **我推荐这个**

**核心**：全站只有 **A 栏一条竖栏**；厂区导览从"第二列"改成 **3D 视图上的一个浮层目录**。

```
┌──────────────┬────────────────────────────────────────────────────┐
│ 淬眸 SuiEye  │ 设备监测中心          [状态chips]  [视角] [复位]  │
├──────────────┼────────────────────────────────────────────────────┤
│ 运营         │ ┌─ 概览卡·可收起 ──────┐                          │
│ ● 智能工厂   │ │ 工艺流程              │                          │
│   ├ 磨矿段   │ │  ● 磨矿段   70%  ›   │        3D 厂区            │
│   ├ 浮选段   │ │  ● 浮选段   86%  ›   │      （视口 1168px）       │
│   ├ 精矿输送 │ │  ● 精矿输送 33%  ›   │                          │
│   └ 尾矿回水 │ │  ● 尾矿回水 87%  ›   │                          │
│   直播墙     │ │ ─────────────────    │                          │
│   实时监控   │ │ 公辅与中控            │                          │
│   仪表盘     │ │  □ 中控室   □ 化验室 │                          │
│   时光机     │ │  □ 药剂间   □ 配电室 │                          │
│   分析工作台 │ └──────────────────────┘                          │
│ 资产         │                                                    │
│   安全巡检   │       [悬停设备 → 详情面板]                        │
│   水质/尾矿  │                                                    │
│   告警/报表  │                                                    │
│   配药助手   │                                                    │
│ 系统         │                                                    │
│   设置       │                                                    │
└──────────────┴────────────────────────────────────────────────────┘
        ▲ 唯一导航                  ▲ 空间目录（浮在 3D 上，可一键收起）
```

**两层分工的判据很清楚：**
- **A 栏 = 功能索引**：我要用"告警中心"，不关心它在哪栋楼 → 直接点
- **浮层目录 = 空间索引**：3D 里那栋楼是干嘛的 / 这段现在什么状况 → 看这里，点它相机飞过去并在 3D 里高亮

**A 栏自身也要改（这轮的重点）：**

1. **名称全站统一**，A 栏与页面 `<h2>` **用同一个字符串常量**（见第五节 `navMap.js`）
2. **「智能工厂」展开成 4 个工艺段子项**，显示健康度与异常数 —— 它就是"我厂现在什么样"的第一眼
3. **分组从 3→4**：`总览 / 生产 / 质量与资产 / 系统`（见下）
4. **去掉重复的角色**：`仪表盘` 与 `智能工厂` 是两回事（一个给数据报表，一个给空间态势），保留；
   但 `分析工作台` 从"运营"移到"质量与资产"（它是化验室里的活儿，不是运营调度）

**A 栏最终结构（13 项 + 4 个子项）：**

```
总览        ● 智能工厂（默认）
              ├ 磨矿段 70%
              ├ 浮选段 86%
              ├ 精矿输送 33%
              └ 尾矿与回水 87%
            直播墙 · 实时监控
生产        仪表盘 · 告警 · 报表
质量与资产  分析工作台 · 安全巡检 · 水质监测 · 尾矿处理 · 配药助手
系统        设置
```

> 分组依据从"运营/资产/系统"（含义模糊，运营与资产边界没人能说清）
> 换成"总览 / 生产 / 质量与资产 / 系统"——按**使用场景**分，不按组织架构分。

| | |
|---|---|
| ✅ 优点 | 重复归零；两条竖栏塌成一条（+80px 给视口）；厂区导览的"空间隐喻"保留但不再占位；支持一键收起做演示沉浸 |
| ❌ 缺点 | 需要新增浮层组件与展开态；A 栏要接设备健康度数据（现成接口 `/api/equipment`） |
| 🎯 适合 | 作为**主推方案**，1 天量级 |

### 方案 C · 「3D 即导航」（重构型，演示效果最佳）

**核心**：3D 页把整条 A 栏**折叠成 56px 图标条**，3D 视口吃满 1332px；厂区导览改成"选中即弹出的抽屉"。

```
┌────┬──────────────────────────────────────────────────────────┐
│ 淬 │                                                          │
│ 眸 │                   完整厂区（1332px）                     │
│ ── │                                                          │
│ ▣  │     点建筑/设备 → 右侧抽屉弹出该处功能                    │
│ ▤  │     抽屉里 = 中控室：生产总览 / 告警 / 报表 / 时光机      │
│ ▥  │                                                          │
│ ◈  │                                                          │
│ ⚙  │                                                          │
└────┴──────────────────────────────────────────────────────────┘
```

- 图标条 hover 出 tooltip（功能名），只在**离开 3D 页**时才展开成完整 A 栏
- 厂区导览彻底消失 —— 因为"点那栋楼"本身就是导航，不需要目录

| | |
|---|---|
| ✅ 优点 | 演示效果最炸（大屏满幅厂区）；重复问题从根上消失 |
| ❌ 缺点 | 违背"任何页面都能一步到位跳转"的可用性常识；评委现场演示时找不到菜单会尴尬；改动面大 |
| 🎯 适合 | 只在**展会/大屏**场景使用，日常不推荐作为默认 |

## 四、推荐：方案 B（理由）

1. **它同时解决两个问题**：重复（B 栏不再是"第二张菜单"，而是"3D 的图例/目录"），
   以及视口窄（竖栏从两条变一条，1440 下 3D 宽度 928 → 1112px）。
2. **它保留了上一轮做的所有工作**：工艺链时间轴、载体建筑、徽标入口 —— 只是搬家，不报废。
3. **它符合"设备是牌面"的定位**：3D 页的主角是厂区，浮层目录是配角；现在配角占了 240px 的主舞台。
4. **它有明确的降级路径**：浮层可收起 → 演示时一键变成"纯厂区"；窄屏自动收起 → 不用再做断点。

## 六、验收口径（用探针，不靠肉眼）

1. **重复检测**：遍历 14 条路由，统计「同一 path 出现在几个地方」→ 目标 **全部 = 1**
2. **命名一致性**：所有页面 `<h2>` 文本 ∈ `navMap` 的 name 集合 → 目标 100%
3. **视口宽度**：1440×900 下 `.viewport` 宽度 ≥ 1100（现状 928）
4. **浮层联动**：点 A 栏"浮选段" → 浮层对应行 `is-active` 且相机 `controls.target` 变化
5. **可收起**：收起后 `.guide-card` 不存在于 DOM，刷新后仍保持收起

## 七、需要老板拍板的三件事

1. **命名方向**：统一成"简短名"（仪表盘 / 告警 / 报表 / 设置 / 时光机）还是"正式名"（生产总览 / 告警中心 / 报表统计 / 系统设置 / 工况时光机）？
   → 我建议**简短名**：侧栏 220px 放得下，且与页面标题一致不会有落差。
2. **方案 A / B / C**：我推荐 **B**。
3. **智能工厂是否展开 4 个工艺段子项**：
   → 我建议**展开**（它是"厂区现在什么样"的第一眼数据），但收起态只显示最长那一条异常摘要。
