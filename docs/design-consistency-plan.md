## 一、诊断：不协调不是审美问题，是"没有共同语言"

### 1.1 令牌（tokens.css）早就写好了，但落地率悬殊

| 页面 | `var(--*)` 使用次数 | 硬编码色值 | 唯一色数 |
|---|---:|---:|---:|
| 尾矿处理 | 269 | 33 | 7 |
| 告警 | 257 | 19 | 11 |
| 水质监测 | 178 | 22 | 8 |
| 仪表盘 | 161 | 12 | 9 |
| 直播墙 | 123 | 27 | 17 |
| **实时监控** | **0** | **76** | **20** |
| **设置** | **0** | 27 | 10 |
| **配药助手** | **0** | 38 | 16 |
| **分析工作台** | **1** | **62** | 19 |
| **安全巡检** | **1** | 44 | 14 |
| 3D 门面 | 37 | **247** | **92** |

→ 5 个页面基本没用令牌；实时监控 76 处硬编码、20 种颜色，等于自带一套色板。
→ 同一个"危险红"，各页分别写 `#f53f3f` / `#ff4d4f` / `#e34d59`。

### 1.2 页头：8 个页面 8 种写法

| 页面 | 页头构成 | 问题 |
|---|---|---|
| 仪表盘 | 标题 + 右上「操作手册」 | 无副标题、无刷新 |
| 告警 | 标题 + 5 个横排统计（无卡片框） | 统计条形态独此一家 |
| 报表 | 标题 + 刷新时间 + 3 个按钮 | 动作区样式独有 |
| 实时监控 | 标题 + LIVE 徽标 + 4 格 KPI + 画面时刻 | 无统一页头 |
| 尾矿处理 | 「尾矿处理 · T1 尾矿浓密机」+ 描述 + 刷新 | 标题带设备名，长度不定 |
| 水质监测 | 标题 + 「数据更新于…」+ 刷新 | 时间放右侧 |
| 分析工作台 | 「浮选 · 分析工作台」+ 实时画面 tag | 组合式标题 |
| 设置 | 标题 + 副标题 | 无动作区 |

→ 页头高度、标题字号（18/20/22 混用）、动作区位置、有无副标题，**没有一条是全站约定**。

### 1.3 KPI 卡：4 种形态

1. **仪表盘**：6 张小卡 + 图标
2. **告警**：5 个裸数字横向排列，靠竖线分隔，无卡片
3. **报表**：4 张卡 + 四色图标（蓝/绿/橙/紫）
4. **尾矿**：4 个数字，第一个 40px、其余 20px（**同组内层级自己就不一致**）
5. **水质**：4 张卡 + 5 张点位卡

→ 数字字号 20~40px 不等；是否带底卡、是否带图标、是否带脚注，全凭各页心情。

### 1.4 图表：五套配色

| 页面 | 图表用色 |
|---|---|
| 仪表盘 | 环形图 7 色（红绿紫蓝橙…） |
| 报表 | 折线红 + 蓝 |
| 尾矿 | 蓝 + 灰 |
| 水质 | 蓝 + 红 |
| 3D 门面 | 平台绿/黄/红 |

→ 品牌色 `#165dff` 被稀释；环形图 7 色是最明显的"拼装感"来源。

### 1.5 版式骨架：留白完全不成体系

从对照图看：仪表盘紧凑、水质极密（5423 字符/屏）、设置极空（1556 字符/屏）。
页面外边距在 16 / 20 / 24 / 32 之间随意取值，卡片内边距同理。

## 二、方案：三层治理 + 三种版式（不是把 13 页做成一个模子）

### 2.1 三层治理

| 层 | 产出 | 解决什么 | 谁负责 |
|---|---|---|---|
| **L1 令牌层** | 扩 `styles/tokens.css` | 颜色/字号/间距/圆角/阴影只有一个来源 | 全站 |
| **L2 骨架层** | 新组件 `PageShell.vue` | 页头结构、页面留白、返回动线 | 12 页统一 |
| **L3 组件层** | `StatCard` / `Panel` / `StatusPill` / `EmptyState` | KPI 卡、内容卡、状态标签、空态 | 按需复用 |

**关键纪律**：一致性靠"页面不能自己决定"，不靠"每页都认真设计一遍"。
L2 落地后，新页面想长歪都没有机会 —— 页头只有一种写法。

### 2.2 三种版式原型（保留合理的差异）

| 原型 | 页面 | 特征 |
|---|---|---|
| **A 门面型** | `/`（3D）、`/livewall` | 满屏、无页面留白、KPI 收在页头 |
| **B 分析台型** | `/monitor`、`/tailings`、`/water`、`/workbench` | 左媒体/右数据、顶部 4 格 KPI 横条 |
| **C 管理型** | `/dashboard`、`/alarms`、`/reports`、`/safety`、`/timemachine`、`/settings`、`/dosing` | PageShell + KPI + 卡片网格 |

三种原型**共用**令牌、页头、KPI、卡片、图表色板；只在"主体区怎么排"上不同。

### 2.3 规范值（建议，待拍板）

| 项 | 值 | 说明 |
|---|---|---|
| 页面外边距 | 20px（上下）/ 24px（左右） | 全站统一，3D/直播墙除外 |
| 页头高度 | 56px，底部 1px 分隔线 | 固定，不随内容变高 |
| 页头结构 | `← 智能工厂` + 标题(20px/600) + 副标(13px/--text-3) + 右侧动作区 | 12 页唯一写法 |
| KPI 卡 | 4 格等宽、高 88px、圆角 8、边框 1px、无阴影 | 少于 4 项时留白不拉伸 |
| 卡片 | 白底、1px `--border-1`、圆角 8、内边距 16 | 无阴影；hover 只变边框色 |
| 字号阶梯 | 12 / 13 / 14 / 16 / 20 / 28 | KPI 数字固定 28 |
| 图表 | 3 色：主蓝 `#165dff` / 中性灰 `#86909c` / 绿 `#00b42a`；红橙**仅**表告警 | 面积填充 12% 透明 |
| 状态色 | 成功 `#00b42a` / 警告 `#ff7d00` / 危险 `#f53f3f` | 只表状态，不当装饰 |

## 四、验收口径（探针，不靠肉眼）

| 口径 | 判据 |
|---|---|
| ① 页头唯一 | 12 页都存在 `.page-head`，高度均为 56px（±1） |
| ② 标题唯一 | `h1` 字号 20px、字重 600，12 页相同 |
| ③ 留白唯一 | 页面根 padding 上下 20 / 左右 24（3D、直播墙豁免） |
| ④ 卡片唯一 | `.panel` 圆角 8px、边框色 `rgb(229,230,235)`、`box-shadow: none` |
| ⑤ 色板唯一 | 单页内出现的十六进制色 ≤ 令牌集合（白名单校验） |
| ⑥ 动线不破 | `qa_hub.py` 仍全绿（返回按钮 ≤140px、点击落 `/`） |

- ❌ 不改业务逻辑、不动接口、不调数据口径
- ❌ 不引入新的 UI 框架（继续 Element Plus + 令牌）
